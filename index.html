Before You Record

1. Use HTTPS and a browser that supports screen capture.
2. Press Start Recording and approve the browser's screen-sharing prompt.
3. Select the source you want to record, if the browser offers one.
4. Allow microphone access if requested.
5. Press Stop & Save and download the video.

If the browser does not offer screen capture, this website cannot bypass that restriction. Installing it does not grant extra Android permissions.
